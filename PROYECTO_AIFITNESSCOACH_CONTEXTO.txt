Flujo funcional principal:
- Pantalla principal: resumen del usuario, módulos principales y objetivo.
- Coach IA: respuesta del entrenador, apoyos, recomendaciones y preguntas rápidas.
- Rutinas: planes y días de entrenamiento con actividades específicas.
- Progreso: métricas del rendimiento, tendencias y nivel de recuperación.
- Futura integración: consumo real del backend con endpoints HTTP para coach, rutinas y recalibración.

Reglas clave del sistema:

- Mantener una arquitectura clara y escalable para backend y frontend.
- Usar un diseño con módulos separados para facilitar pruebas y extensión.
- Priorizar un MVP funcional antes de personalizar mucho la UI.
